# Support

Account-level default for public repositories under `augbastos`.

## Where to go

| You want to | Go to |
|---|---|
| report a bug | that repository's **Issues**, bug report template |
| ask for a feature | **Issues**, feature request template |
| ask how something works | **Issues** - questions are welcome, there is no separate forum |
| report a vulnerability | [SECURITY.md](SECURITY.md), never a public issue |
| contribute a change | [CONTRIBUTING.md](CONTRIBUTING.md) |

Some repositories have Discussions turned off. Where they do, an issue is the right place for a
question and it will not be closed for being one.

## Before you ask

Say which version, which operating system, and what you actually ran. "It does not work" and a
screenshot of a collapsed stack trace turn one exchange into four.

A minimal reproduction is the single most useful thing you can attach.

## What these projects are

Personal projects, published because they are useful, maintained by one person in their own
time. Some are polished; some are experiments that were interesting enough to publish and are
labelled as such in their README.

None of them is a supported product. There is no ticket queue and no response guarantee. If
something here is load-bearing for you, read the licence and plan for the maintainer being
unavailable - that is the honest position, and it is better said than discovered.

## Commercial use
